# Professional Self-Assessment – Jordan Jenkins

## <ins>Introduction</ins>
Throughout my Computer Science program and Capstone experience at Southern New Hampshire University, I have grown from a student of coding fundamentals into an adaptive software engineer capable of designing, implementing, and securing complex computing systems. My capstone artifacts - ExceptionsEnhancement, 3DSceneEnhancement, and AndroidAppEnhancement - represent not only technical accomplishments but also milestones in my professional growth. Together, they demonstrate how I apply algorithmic reasoning, secure design principles, and collaborative tools to deliver reliable computing solutions. This self-assessment reflects on my learning journey and how I now view myself as a professional ready to contribute to the field of computer science.

## <ins> Professional Growth and Technical Development </ins>
Early in the program, I focused primarily on getting code to work and understanding basic principles. Over time, I learned to approach software development as a process that integrates design planning, documentation, testing, and maintenance.<br/>
- In `ExceptionsEnhancement`, I applied structured exception handling and input validation to produce reliable Python code that communicates clearly to technical and non-technical users. This reinforced my ability to translate logic across languages while preserving functionality.<br/>
- The `3DSceneEnhancement` project challenged me to think about efficiency and scalability. I refactored a legacy OpenGL program using modern C++ practices such as smart pointers and modular design patterns. This enhancement deepened my understanding of memory management, object-oriented principles, and graphics pipeline architecture.<br/>
- With `AndroidAppEnhancement`, I shifted focus toward software security and user experience. Implementing parameterized SQL queries, password hashing, and modular database design strengthened my ability to write a secure application that reflects real-world industry practices.

## <ins>Communication and Collaboration</ins>
Effective communication has been essential to my success. Through GitHub, I maintained organized branches for each enhancement and documented every change. These practices mimic real-world version control workflows and collaborative development environments.
Beyond code, I honed my ability to communicate technical ideas clearly to varied audiences. Whether documenting shader functions, explaining exception flow, or describing database encryption methods, I learned to write with precision and adaptability. This skill ensures I can bridge the gap between technical and non-technical users in professional settings.

## <ins>Ethical Responsibility and Security Mindset</ins>
Security has become a central theme in my work, especially after recognizing how poor design can lead to vulnerabilities. In the Android artifact, I addressed SQL injection and weak password storage - two of the most common real-world exploits - by using parameterized queries and cryptographic hashing. Similarly, my attention to exception handling and resource cleanup in the C++ and Python artifacts reflects a proactive effort to prevent instability and unintended behavior.
This emphasis on security demonstrates a broader ethical responsibility: to protect users and data integrity. I now approach development with a “trust but verify” mindset—anticipating misuse, validating input, and ensuring code fails safely.

## <ins>Career Readiness and Future Goals</ins>
Completing this program has given me the confidence and the practical foundation to succeed in a professional software engineering environment. I am comfortable working across platforms and languages such as C++, Python, and Java. I also have experience with DevOps concepts like version control, deployment environments, and testing pipelines. Moving forward, I intend to apply these skills in roles that bridge software engineering and cybersecurity, where I can continue to build secure, efficient, and user-focused systems.

## <ins>Conclusion</ins>
The Capstone experience has reflected my journey from learning how to code to understanding how to engineer solutions. By enhancing existing projects rather than starting from scratch, I demonstrated the ability to evaluate, improve, and communicate complex systems—skills that mirror real-world software maintenance and development practices. I now view myself as a well-rounded professional who values clarity, security, and collaboration.
